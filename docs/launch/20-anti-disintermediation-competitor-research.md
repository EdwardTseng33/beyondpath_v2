## 1 · Pro360（台灣外包平台）防跳過機制盤點

### 1.1 平台定位
- 台灣 freelance + 接案平台、媒合裝修 / 設計 / 行銷 / 諮詢類案件
- 主要客群：台灣個人 / 中小企業

### 1.2 防跳過機制（公開條款摘要）
- **非競業期**：撮合後 90 天內、雙方不得繞過平台直接交易
- **違約金**：違者賠 3 倍服務費
- **平台監測**：透過站內訊息監測異常聯絡資訊外露行為（電話 / email / Line ID 觸發 flag）
- **訊息控制**：站內訊息中過濾外部聯絡方式（自動 mask）

### 1.3 強制度評估
- **中等強制度**：條款明訂但實際執行有限、依賴平台主動發現
- 對個人 client 約束力中等、對工作室 / 公司客戶較強

### 1.4 BeyondPath 可借鑒
- ✅ 90 天非競業期 → BeyondPath 採 **6 個月**（30 天溝通強制 + 6 個月 anti-disintermediation 期）
- ✅ 3 倍違約金 → BeyondPath 採蓄意挖客戶 **× 3 倍**（一般跳過僅 × 2 / × 1.5）
- ❌ 站內訊息自動 mask → Beta POC 階段不導入（增加實作成本、降透明度）
- ✅ 條款明訂為基礎 → BeyondPath terms.html §8 已涵蓋

## 2 · Upwork（國際）防跳過機制盤點

### 2.1 平台定位
- 全球最大 freelance 平台（含 SaaS + 系統整合 + 工程外包）
- 主要客群：北美 / 歐洲企業 + 全球 freelancer

### 2.2 防跳過機制（公開條款摘要）
- **非競業期**：合作關係建立後 24 個月內、雙方不得直接合作
- **違約金 / 跳過費**：依 Plan tier 不同（Basic / Plus / Enterprise）：
  - Basic：跳過費 = 該年度雙方合作總額之 ~15%（最低 USD 2,500）
  - Plus：跳過費降低
  - Enterprise：可協議買斷（Conversion Fee）
- **平台監測**：
  - 訊息中聯絡資訊自動偵測（email / 電話 / Skype / WhatsApp）
  - 雙方 IP / device 重疊偵測
  - 異常付款 pattern flag
- **法律訴訟**：Upwork Inc. 真實對跳過者提起訴訟（曾有公開案例）

### 2.3 強制度評估
- **高強制度**：法務 / 監測 / 條款三位一體
- 但實際執行也產生反彈（freelancer 抱怨「24 個月太長」、平台被批 "anti-freelance"）

### 2.4 BeyondPath 可借鑒
- ❌ 24 個月非競業期 → 太長、不適合 Beta POC、採 **6 個月**（4 倍縮短）
- ❌ Conversion Fee 買斷機制 → Beta POC 不導入、改為「主動揭露免責」設計
- ❌ 訊息監測 → Beta POC 不導入（隱私顧慮 + 實作成本）
- ✅ 條款明訂 + 違約金 → BeyondPath 已採用

## 3 · Fiverr（國際）防跳過機制盤點

### 3.1 平台定位
- 全球 gig economy 平台、單次小型交付為主
- 主要客群：全球個人 / 小企業

### 3.2 防跳過機制（公開條款摘要）
- **平台溝通強制**：「You may not solicit Buyers to bypass Fiverr's marketplace」
- **聯絡資訊禁止**：訊息中含 phone / email / Skype / external link = 違規、警告 → 終止帳號
- **配對期間全程強制**：不限「N 天」、整個雙方關係期間都須走 Fiverr
- **違反後果**：終止帳號 + 法律追訴權

### 3.3 強制度評估
- **高強制度**：政策最嚴、實際執行最直接（自動觸發終止）
- 對 freelancer 端壓力大

### 3.4 BeyondPath 可借鑒
- ❌ 「整個關係期間都不得繞過」→ 太嚴、會嚇跑用戶
- ❌ 訊息自動過濾 → Beta POC 不導入
- ✅ 違反 = 終止使用權 → BeyondPath terms.html §8.2 已採用
- ✅ 明確政策 → BeyondPath terms.html §8 已採用

- 違約金保守版：× 2 / × 1.5 / × 3

### 5.4 主動揭露免責機制（BeyondPath 獨家設計）

雙方於配對 30 日內主動向平台揭露「我們決定直接合作」、平台依個案另議（通常為 take rate 一次性結案、無違約金倍率）。

**為什麼設計這個**：
- 業界各平台都「禁止跳過、違反就罰」、用戶體驗差
- BeyondPath 採「歡迎透明、強制違反才罰」、降低用戶反感
- 法律意義：證明平台不過度限制競爭（公平交易法 §19 合規）

## 6 · 公平交易法 §19 風險評估

### 6.1 §19 條文
公平交易法 §19：「事業不得為下列各款行為之一、而有限制競爭或妨礙公平競爭之虞...」
- 第 4 款：以脅迫、利誘或其他不正當方法、使他事業不為價格之競爭、參與結合、聯合或為垂直限制競爭之行為

### 6.2 風險評估表

| 條款 | 風險 | 緩解措施 |
|---|---|---|
| 6 個月非競業期 | 🟢 低 | Pro360 採 90 天、BeyondPath 6 個月仍在合理範圍；Upwork 24 個月才有實際 §19 訴訟 |
| × 3 倍違約金（蓄意挖客戶）| 🟢 低 | Pro360 也採 × 3、業界慣例 |
| 6 個月禁用 | 🟡 中 | 限制較強、但僅針對「蓄意挖客戶」此單一情境、非全面禁止 |
| 主動揭露免責 | 🟢 低 | 主動降低限制效力、利於 §19 合規 |
| 違約金 50/50 分配 | 🟢 低 | 平台不獨享、減低「平台牟利」之嫌 |
| 業界調研附錄 | 🟢 低 | 透明揭示「BeyondPath 採保守版」、利於公平交易委員會理解 |

### 6.3 整體風險
🟢 **低風險**。BeyondPath terms.html §8 設計：
- 短期約束（6 個月 vs Upwork 24 個月）
- 保守倍率（× 2 / × 1.5 / × 3 vs 業界 × 3-5）
- 主動揭露免責
- 透明附錄
- 違約金不獨享

= 公平交易法 §19 訴訟風險遠低於業界水準。

- Edward 親口拍板要調整

### 7.3 律師上線觸發
PMF 階段不外送律師（Edward 5/28 拍板）。以下情境再評估上律師：
- 月成案 ≥ 10-20 案
- 第 1 起違約金實際請求
- 接 SI 大案（ACV ≥ NT$ 500K）
- 拓海外市場（GDPR / 美國各州 freelance 法）
