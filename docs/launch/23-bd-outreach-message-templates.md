## 1. 套 1 · LINE / iMessage 老朋友直接版（中文）

### 1.1 初次接觸（W1 open）

```
[對方名]

最近搞了個東西 BeyondPath、台灣第一個 AI 接案平台、我自己當 CPO。

簡單講：你描述要做的 AI 交付（文案、圖像、影音、自動化），我配對到對的 AI 工作者、我親自陪跑交付。

Beta 階段、無平台費。

想找幾個信任的人試做個案子、要不要先聊 30 分鐘？

—— Edward
```

**設計邏輯**：
- 不到 100 字、5 秒讀完
- 「我自己當 CPO」= 朋友最在意「這跟你有關嗎」、放最前
- 「Beta 階段、無平台費」= 朋友最在意「我會不會被當白老鼠付錢」、解這顧慮
- CTA 「30 分鐘」= 不負擔的時長、容易答應

### 1.2 提案（對方回 yes 後 24h 內）

```
好 那這週你方便哪天？

我先帶一個案子的點子來、不要你想破頭：

我猜你公司現在 [基於 file #21 備註欄 個人化句]、所以我想搭一個 [試做案具體點子 1-2 句]、預算抓 NT$ X 萬內、6 週內結案。

你聽完覺得不對 我們換、不勉強。

幾點方便？
```

**設計邏輯**：
- 「我先帶點子來、不要你想破頭」= 替朋友 take ownership、不是把工作丟回給他
- 「個人化句」依 file #21 備註填（例：「最近擴 AI 客服」/「最近 outbound 卡關」）
- 「不對我們換」= 留 escape hatch、不施壓

### 1.3 跟進（對方沒回 1 週後）

```
[對方名]

上週 BeyondPath 那個丟你了 還沒回我也正常 我不催。

不過想到一個更直接的方向：[試做案點子 v2]、預算更輕（NT$ X 萬內）、3 週結案。

你覺得不適合就直接說 我去找別人試。
```

**設計邏輯**：
- 「還沒回我也正常」= 不施壓、朋友最怕被當 lead 追
- 「想到更直接的方向」= 給對方理由 reopen 對話、不是 ping 同樣 question
- 「你覺得不適合就直接說」= 給對方 easy out、保住關係

### 1.4 Retainer 升軌（一次性結案後 2 週內）

```
[對方名]

上個案子收得很順 你那邊收到 [deliverable] 還順嗎？

跟你提一個想法：

我看你公司每月都有類似的 [需求 type]、那不如月繳 NT$ 3 萬、同一個 worker 持續陪跑、每月 W1 brief / W2 deliver / W3 review、不用每次重新解釋你公司。

不適合也沒關係 我們就繼續 case by case。

要不要看一頁 deck 我寄給你？
```

**設計邏輯**：
- 「上個案子收得很順」= 開場呼應結案、建立連續性
- 「我看你公司每月都有 X」= 觀察過、不是亂推銷
- 「不適合也沒關係」= 給 out、降壓力
- 「要不要看一頁 deck」= CTA 是「看 file #22」不是「簽合約」、step 縮小

## 2. 套 2 · Email 商務版（中文）

### 2.1 初次接觸（W1 open）

**主旨**：BeyondPath Beta POC 邀請 · 30 分鐘介紹 + 試做案合作

```
[對方稱謂] 您好，

我是 Edward Tseng、BeyondPath 創辦人 / CPO。

BeyondPath 是 2026 年起步的 AI 接案平台、解決一個具體問題：

> 你公司需要 AI 交付（文案、圖像、影音、自動化），但找不到夠專業的 AI freelancer、外包公司又太貴、in-house hire 又承擔不起。

我們的模式 = 你描述需求、我們配對到對的 AI 工作者、平台陪跑交付。

目前 Beta 階段、無平台費、選 5-7 位信任客戶試做。

想找您聊聊 [對方公司名] 的 AI 需求、看看試做案是否合適。

30 分鐘對話、線上或實體都可。下週四上午、或週五下午、您方便嗎？

謝謝
Edward Tseng
BeyondPath · CPO
hi@beyondpath.com.tw · LINE @beyondpath
beyondpath.com.tw
```

**設計邏輯**：
- 主旨明確 = 不像 cold sales、像 POC 邀請
- 第二段「具體問題」= 對方一秒判斷「跟我有關嗎」
- 「Beta 階段、無平台費」= 解「不會被當白老鼠」
- 「下週四上午、或週五下午」= 給選項而非「您方便時間」、推進 CTA
- Footer 完整 = 不假冒、可信度

### 2.2 提案（對方回 yes 後 24h 內）

**主旨**：BeyondPath × [對方公司] 試做案點子 · W4-W6 結案

```
[對方稱謂] 您好，

謝謝快速回覆。如約定明天上午 10:00 線上、會議連結：[Calendly / Google Meet 連結]

明天我會帶一個具體試做案點子來、不需您現場想破頭：

**試做案點子**
- 範圍：[1-2 句具體 deliverable]
- 預算：NT$ X 萬內、單次結案
- 時程：6 週、預計 [日期] close
- 對應 [對方公司] 的需求：[基於 file #21 備註的個人化 1-2 句]

明天會議我會：
1. 帶 BeyondPath POC 一頁 deck（5 分鐘）
2. 過試做案具體點子（10 分鐘）
3. 聽您回饋、調整範圍（15 分鐘）

如果聽完不適合、我們調整或換方向、無壓力。

明天見
Edward
```

**設計邏輯**：
- 主旨直接點「試做案點子」= 預告會議價值、提高 show-up rate
- 「不需您現場想破頭」= reduce 對方準備壓力
- 「明天會議我會」3 條 agenda = 確定感、商務感
- 時長分配（5+10+15）= 對方知道會議 30 分鐘怎麼花

## 5. Edward 個人化補強清單

霍爾的模板只是 baseline、Edward 送出前必個人化：

### 5.1 每封訊息必填的個人化點

1. **對方名** = 對方稱呼方式（暱稱 / 全名 / 職稱、看關係）
2. **個人化句** = 從 file #21 備註欄抓 1-2 句（對方公司近況 / 痛點 / 上次見面聊到什麼）
3. **試做案點子** = 依對方 vertical 想 1-2 個具體案例（不是「AI 交付」這種模糊詞）
4. **預算數字** = 依對方 vertical + 公司規模 + file #21 預估 ACV 填具體 NT$ X 萬

### 5.2 不要套模板的部分

- **不要每個人都用一樣的開頭** = LinkedIn DM 一看就知道是 mass DM、信任歸零
- **不要硬塞所有 4 個 value prop** = retainer pitch 訊息只挑對方最關心的 1-2 個
- **不要趕時程** = 對方回信節奏不一、跟進不要太密（1 週 1 次上限）

### 5.3 避雷

- ❌ 不要用「親愛的」「您好您好」這種重複客套
- ❌ 不要在 LinkedIn DM 寫 200+ 字 long copy（會被 ignore）
