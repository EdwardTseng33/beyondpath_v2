## 0. TL;DR

| 階段 | 軸 | 目標 |
|---|---|---|
| **W1-W6 純一次性 BD** | 朋友圈試做案接 1-3 個 | 累積信任 + 結案證明 + retainer pipeline 候選 |
| **W7 起 retainer pitch** | 跟結案的一次性 client 試月繳 | 轉化率 target 30%、即每 3 結案 = 1 retainer |
| **W8-W12 retainer 累積** | 3-5 個月繳客戶 | Y1 POC #3 雙邊買單第二第三證據 |
| **失敗 path** | Month 2 取消 / pitch 拒絕 | SOP 含早期偵測 + 退費條款 + 第二 pitch 對象 backup |

**霍爾 核心 thesis**：retainer 不是冷推得來、是「**第一案做好 → client 信任 → 升級月繳**」自然轉化。一次性 BD 是 retainer 的 funnel top、不是分開兩個 product。

### 1.3 開場白（面談前 5 分鐘 + 面談首 15 分鐘）

**面談前 LINE 確認**（咖啡 30 分鐘前）：

```
[對象名]、等下見。

待會我會問你 3 件事：
1. 你最近最想用 AI 解決的事是什麼
2. 你試過哪些 AI 工具或工作者、結果如何
3. 你願意花多少錢買一次「絕對交付的 AI 工作流」

不是要推銷、是想搞清楚 BeyondPath 該不該為你存在。
```

**面談首 15 分鐘 script**（Edward 講）：

> 「先聲明、我今天不是來賣東西的、我是來搞清楚 BeyondPath 該為誰存在的。
>
> 你應該知道、現在 AI 工具一堆、AI 接案者一堆、但你要把錢交出去、心裡其實沒底——這個人真的會用 AI 嗎？他交出來的東西真的是 AI 做的還是他自己手做的？品質保證在哪？出包誰負責？

>
> 我先問你 3 件事、再決定要不要為你做。」

### 1.4 試做案範圍 + 預算 + 時間談法

**典型試做案 spec**（4-6 週 · NT$ 8-25 萬）：

| 元素 | 內容 |
|---|---|
| **交付物** | 1-2 個 specific AI 交付（文案 + 圖像、或自動化流程 + 報表）|
| **時程** | 4-6 週 · 含 1-2 milestone |
| **預算** | NT$ 8-25 萬（依案況、平台抽 17-20%）|
| **付款** | 30% 簽約 / 30% 中期 / 40% 結案（見 file #18）|
| **驗收** | Acceptance Criteria 在合約寫死、不滿意 60 day 內可退 40% 結案款 |

**Edward 拍板權**：
- ≤ NT$ 15 萬：Edward 直接 close
- NT$ 15-25 萬：需 1-2 milestone 拆解
- ≥ NT$ 25 萬：先試做 1 milestone 看品質、再簽全約

## 2. Retainer Pitch 軸（W7 起）

### 2.1 Retainer pitch 觸發條件

**何時 pitch**：一次性案結案後 1-2 週內、雙邊 NPS ≥ 50、client 主動讚揚交付品質時。

**pitch 對象排序**：
1. 試做案 1 結案 client（信任最高、第一個 pitch 目標）
2. 試做案 2 結案 client（W4 結束）
3. 試做案 3 結案 client（W6 結束）

### 2.2 Retainer pitch 訊息模板

**情境 1 · LINE / Email pitch（試做案結案後 1 週）**

```
[對象名]、

我們上次那個 [案件 specific] 結完了、雙邊都很順。

我有個想法想跟你聊。

你之前說過 [client 提過的痛點，例：「每個月都要重新找人做這類案」/
「我需要的不是一次性、是持續優化」]——

要不要試試 BeyondPath 的「持續交付方案」？

簡單講：月繳 NT$ X 萬、我們維持 [上次的 worker] 替你做、
每月 [X 件 deliverable]、含維護 + 持續優化、有變動需求也彈性處理。

不是綁約、第一個月可試運、不滿意可退。

下週咖啡 30 分鐘細聊？我會帶一頁提案給你看。

Edward
```

**情境 2 · 面談時 pitch（結案 NPS 回收時）**

> 「[對象名]、這個案做完滿意嗎？
>
> [等對方答]
>
> 太好了。我問你一件事——你以後類似的需求、是會繼續發包給我們、還是會自己再找 AI 工作者？
>
> [等對方答]
>
> 我想到一個對你可能更省事的選項。要不要試試月繳？
>
> 月繳 NT$ X 萬、含 [固定 deliverable] + 維護 + 變動需求彈性處理。
>
> 比你每次重新發包省時、品質穩、worker 固定就是上次那位、不用重新磨合。
>
> 我可以給你看一頁提案。要試試嗎？」

---

### 2.3 Retainer 試做提案 1 頁（PDF / Notion 格式）

**模板結構**（蘇菲負責設計、霍爾審 narrative）：

```
─────────────────────────────────────────
BeyondPath Retainer 持續交付方案
For: [Client Name]
By: Edward Tseng | beyondpath.tw
─────────────────────────────────────────

【你的需求】
• 持續性 AI 交付（[specific 內容]）
• 品質穩定、不用每次磨合新人
• 變動需求彈性

【提案內容】

★ 月繳 NT$ X 萬（含稅）
★ 期間：3 個月起、隨時可終止（提前 30 天通知）

★ 每月 deliverable：
   - [Deliverable A]（每月 X 件）
   - [Deliverable B]（每月 Y 件）
   - [Maintenance Z]（持續支援）

★ Worker：[W01 / W03 / W06 名]（你已合作過）

★ SLA：
   - 緊急需求 24h 內回應
   - 一般需求 72h 內 deliverable
   - 月度 check-in 1 次（30 分鐘）

【為什麼選 Retainer？】

✓ 比一次性發包省 25-40% 總成本
✓ 同一 worker · 不用重新磨合
✓ AI 工具持續更新、不必自己追新
✓ 平台仲裁兜底、出包我擔

【試運條款】

第一個月不滿意、可全額退費。
第二個月後、提前 30 天通知終止、無違約金。

【下一步】

口頭 OK → 簽合約 → 綠界定期扣款設定 → 啟動

—— Edward, 2026/X/X
```

### 2.4 Retainer 提案後 follow-up SOP

**Day 0**：面談 / pitch 完、把提案 1 頁 LINE / email 給 client
**Day 3**：LINE follow-up 一句「提案看了嗎？有問題隨時問我」
**Day 7**：若無回、再 follow-up 一次「下週要約細聊嗎？」
**Day 14**：若仍無回 = soft close（不催、留 backup 第二 pitch 對象）

**Edward 親動**：所有 follow-up 親發、不委派蘇菲（信任度敏感）。

## 3. Retainer 累積 target · W8-W12

### 3.1 累積路徑

| W | retainer 累積 | 來源 |
|---|---|---|
| W7-W8 | 1 個 | 試做案 1 client（C01）轉化 |
| W9-W10 | 2 個 | + 試做案 2 client 轉化 |
| W11-W12 | 3-5 個 | + 試做案 3 + 朋友圈直推 1-2 個 |

**轉化率假設**：
- 試做案結案 → retainer pitch：100%（每個結案 client 都 pitch）
- Pitch → 簽約：30-40%（每 3 個 pitch ≈ 1 簽）

**容錯**：若 W10 仍只 1 個 retainer、開始**直推 retainer pitch**給朋友圈未跑過試做案的對象（風險高、信任度低、轉化率 < 20%、但累積基數大）。

---

### 3.2 Retainer 客戶月度 check-in SOP

每個 retainer client、每月 1 次 30 分鐘 check-in：

| 項目 | 內容 |
|---|---|
| Deliverable review | 上月交付清單 + 滿意度 |
| 變動需求 collection | 下月想做什麼新 / 不同 |
| NPS 收集 | 0-10 score + 一句 comment |
| Renewal signal | client 有沒有提終止 / 想擴大 / 想減量 |

**Edward 親跑**：第一個 retainer client 前 3 個月都親跑、之後可委派蘇菲（但 Edward 必看 check-in 紀錄）。

## 4. 失敗 Path · Month 2 想取消怎麼處理（5/28 audit §2.3 列）

### 4.1 取消信號早期偵測

**Day 30 check-in 警示信號**：
- Client 抱怨 deliverable 品質 / 數量 / 時效
- Client 提「下個月可能 budget 緊」
- Client 月度 NPS < 30
- Client read message 但不回（72h+）

**信號出現 → 啟動 retention SOP**：

### 4.2 Retention SOP（按優先級）

**Level 1 · 立刻面談**（信號出現 24h 內）

Edward 親 LINE：

```
[對象名]、最近這個月的 deliverable 你還順嗎？

我感覺有些東西沒對到、想跟你 face-to-face 聊 30 分鐘。

下週某天可以？我可以調整方案、不一定要照原本跑。
```

**Level 2 · 方案調整**（面談時 offer）

- 月費下調 20%（NT$ 3 萬 → 2.4 萬）試 1 個月
- 或 deliverable 減量保持月費
- 或暫停 1 個月、保留 worker 不換人
- 或轉一次性 case-by-case（脫 retainer）

**Level 3 · 試運期退費**（合約寫死、必執行）

- 第一個月不滿意 → 全額退費（已寫合約）
- 第二個月起、提前 30 天通知 → 無違約金、按比例計費

**Level 4 · 善別離 + 學習**

- 結案後 1-2 週 Edward 親跑「為什麼決定終止」訪談 30 分鐘
- 記錄到 `projects/beyondpath/research/retainer-churn-analysis.md`
- 用來改下一個 retainer 提案 + worker 匹配

---

### 4.3 取消後是否回頭嘗試？

**情境分類**：

| 取消原因 | 是否再 pitch | 何時 |
|---|---|---|
| Budget 緊（短期）| ✅ 是 | 3-6 個月後再 LINE「最近還順嗎」 |
| Worker 不對盤 | ✅ 是 | 換 worker 後再 pitch |
| Deliverable 對不到 | ✅ 是 | 重新 scope 後 pitch |
| 公司方向變、不需要 AI 了 | ❌ 否 | 不糾纏、留聯絡 |
| 對 BeyondPath 失信任 | ❌ 否 | 善別離、不再聯繫 |

## 5. 失敗 Path · Retainer pitch 被拒絕

### 5.1 拒絕信號分類

| 拒絕語 | 真實意思 | 應對 |
|---|---|---|
| 「我再想想」 | 70% 是軟拒 | 給 1 週後 follow-up、再無回 = soft close |
| 「最近沒預算」 | 真的沒預算 | 3-6 個月後再 LINE |
| 「我們公司還沒需要 AI 持續做」 | scope 沒對到 | 改 pitch 角度（突顯持續優化、不是持續發案）|
| 「比較想自己內部養人」 | 不是 BeyondPath market | 善別離、留聯絡 |
| 「比一次性發包貴」 | 沒看懂 retainer 價值 | 重 pitch 時拿 file #19 月繳定價區塊文案、突顯持續優化價值 |

### 5.2 拒絕後不糾纏原則

- 第一次 pitch 拒絕 → soft close、3-6 個月不再主動推
- 拒絕後立刻不糾纏 = 留下「Edward 不死纏爛打」的好感
- 一次性案來、繼續歡迎（不要 retainer 不等於不要案）

## 8. 霍爾的策略 verdict

> **一次性 BD 是 retainer 的 funnel、不是分開兩個 product**。

不要在 W1-W6 同時推一次性 + retainer、會分散 Edward 注意力。

**節奏**：
- W1-W6：純一次性、累積結案信任
- W7-W12：每結案 = 一次 retainer pitch
- W13+：retainer 累積至 3-5 個 = Y1 POC #3 雙邊買單第二第三證據

**核心信念**：
- Retainer 不是冷推得來、是**信任複利**
- 第一個 retainer 簽下來 = 整個 BeyondPath product-market fit 證據
- 失敗 path 不糾纏、留好感 = 長期客戶池
