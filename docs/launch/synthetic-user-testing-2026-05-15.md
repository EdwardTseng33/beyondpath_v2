## 2 · 跨 persona 高頻 PAIN POINTS（critical / high）

### 🔴 P0 · Critical（多 persona 提 + 直接擋 submit）

#### P0-1 · Worker apply Step 2 paste-back 體驗斷裂
**5/6 worker 都提**（W01 / W02 / W03 / W04 / W05）

> W01：「為什麼不直接在這邊跑就好」

**根因**：Step 2 把用戶丟去 ChatGPT/Claude 自己跑 30 min 訪談、回來貼 JSON。流程斷裂 + 中年新手 (W04) 直接迷路 + 高 tier (W05) 覺得不夠尊重。

**Fix priority**: 規劃 Worker apply server-side chat 介面（5-7 day sprint backlog 已紀錄）

#### P0-2 · Demo workers banner 讓 client 冷掉一半
**4/6 涉及（C01 / C03 / W01 / W03）**

> C01：「以為按下去就有 5 個人選、結果是等 Edward email、那我為什麼不直接 email Edward」

**根因**：Step 04 黃色 Beta · demo banner 雖然誠實、但用戶 expectation 從「即時配對」掉到「等 24h email」、信任落差。

**Fix priority**: Banner 文案改「目前 X 位實名 worker 在 pipeline、Edward 24h 內會從中挑 3 個最匹配的給你」（給數字降焦慮）—— 30 分鐘 fix

#### P0-3 · Submit 後不知道接下來怎樣（無 email confirmation）
**多 persona 反映 anxiety**（W02 / W04 / W05 / C01 / C04 / C05）

## 5 · 對 BeyondPath POC 的整體判斷

### Synthetic test 顯示的市場 fit signals

✅ **AI Parse + 結構化 brief** = client 端最強 delight、是真實差異化
✅ **3 層考核 + AI Workflow Proof Profile** = worker 端 attractive、跟既有 freelance platform 區別開
✅ **邀請制** = 篩品質、降低 noise、雙邊都 appreciate
✅ **跨 client 領域 (D2C / B2B / 餐飲 / 個人 IP / Enterprise / NPO) submit 率 4/6 yes** = product 概念站得住

### 主要 conversion 風險

🔴 **Worker side**: 中年新手 (W04) 直接擋 + 高 Tier (W05) 不滿 → 流程「中段」最強、頭尾兩端 (新手 + 資深) 流失
🔴 **Client side**: Demo workers banner 信任落差 → submit 後失去 momentum
🟠 **B2B / Enterprise** 流程缺失 → 大金額流失到競品（Toptal / 直接 email founder）

### 對 BD 的建議

**首批 5-10 個 lead 該找誰**（基於 persona 反饋）：
- ✅ **W01 / W03 / W06 類型** worker（25-35 歲 / AI fluent / 已有 portfolio · 走完不卡）
- ✅ **C01 / C04 類型** client（32-29 歲 / D2C 或 個人 IP / 預算 NT$50-80k · 對 AI 開放 · submit 率高）
- ⚠ **W04 類型** 中年新手 worker、**C05 類型** Enterprise client 暫不發 BD（流程沒準備好接）

POC 階段先打「sweet spot」persona、累積成功案例 + 收 testimonial、再回頭擴大 onboarding 流程容納頭尾 persona。
