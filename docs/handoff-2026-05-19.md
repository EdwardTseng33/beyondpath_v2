## 3 · 整個 PMF 配對閉環全 live

```
1. client 送 brief (landing.html?role=client → app.html Step 01-04)
   → bpClientIntake.submit
   → Supabase client_intakes INSERT (status='new')

2. Edge Function notify-lead-slack 觸發
   → 內部 call match-workers (HTTP)
   → match-workers 抓 worker_unified_v 該 vertical + adjacent
   → 跑 5 維 scoring (tier 25 / capacity 20 / domain 30 / L_score 15 / mercy 10)
   → 寫 client_intakes.match_result (Top 5) + matched_at
   → return Top 5 + breakdown
   → 塞進 EDWARD_ADVISOR_PROMPT
   → Slack 通知 Edward (含 Top 3 worker 推薦 + 為什麼適配)

3. Edward 開 admin.html
   → 看 pending workers + approve/reject/archive
   → 看 client_intakes + 跑配對 (重跑 match-workers OK)
   → 從 Top 5 選 1-N 位 worker
   → 寫訊息（optional）
   → 按「寄邀請信」
   → bpAdmin.sendDecisionEmail call send-decision-email Edge Function
   → 對每位 worker 生 JWT token (HS256 · 7 day exp)
   → token_hash SHA-256 寫 worker_decisions
   → Resend 寄 dark-theme email (含 accept/decline link · token in URL)

4. worker 收 email → 點 accept 或 decline link
   → 跳 worker-accept-decline Edge Function
   → JWT verify
   → 寫 worker_decisions.decided_at + decision
   → 302 redirect landing.html?worker_decision=success&action=accept|decline

5. landing.html EWorkerDecisionBanner 監聽 query
   → 顯示「已接受配對邀請」or「已記錄你婉拒」or「連結已過期」
   → 清 URL query 不重複顯示

6. Edward 開 admin.html DecisionsTab
   → 看 worker_decisions 紀錄 (誰接 / 誰拒 / 何時)
   → 進下一個案
```

**Edward 從「客服 + 媒合 + 通知」變成「拍板 + 督導」**。
