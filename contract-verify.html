合約查驗

上傳合約 PDF + 輸入合約 ID、自動比對 SHA-256 hash 確認本機 PDF 是否為 BeyondPath 平台正本。 任何人可查、無需登入。回傳資料僅含合約 metadata（不含雙方 email、不含 PDF URL）。

查驗原理

BeyondPath 產生合約 PDF 後、會把 PDF 的 SHA-256 hash 寫進資料庫。任何人取得 PDF 都可比對：

  1. 輸入合約 ID + 上傳手上的 PDF
  2. 本頁在瀏覽器內計算上傳 PDF 的 SHA-256 hash（不上傳到伺服器）
  3. 查詢平台資料庫該合約 ID 的 hash
  4. 比對兩個 hash 是否一致 · 一致 = 確認為平台正本

說明：PDF 不會上傳到伺服器、只在瀏覽器內 hash。 平台只回傳 metadata（status / 簽署時間 / handle 匿名化 / hash 比對結果）。 不洩漏雙方 email、不洩漏 PDF URL。
