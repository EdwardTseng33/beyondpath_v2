BeyondPath · AI 時代的工作配對網路。

給品牌主 · 給接案者 · 給雙方信任的閉環。

我們不是另一個 Upwork、不是更聰明的 Fiverr、也不是「AI 自動發包」工具。BeyondPath 處理的、是 AI 時代真正難的那一塊：當人人都像專家、你怎麼知道誰真的能交付。

2026 年起、台灣品牌主面對的問題不是「找不到人」、而是「找到的人到底會不會」。BeyondPath 用 AI 拆解需求、認證化供給、Milestone 驗收、Tier 飛輪——把「找錯人」「管錯案」「驗不了收」這三件事的不確定性降下來。

第一批我們不假裝全自動。AI 初審、人工覆核、案例累積——先驗證、再平台化。

PROTOCOL · 12 步流程協定

從模糊需求到可驗收交付、12 步走完。

每一步都有明確的負責人、產出物、失敗備援。不是流程圖好看、是品牌主第一次合作時可以攤開來看「我們會怎麼幫你」的真實工作流。

01
選領域 + 上傳需求
客戶在 15 個垂直領域選主類、上傳 brief（可文字 / 錄音 / 截圖）。不需要先想清楚規格、只要說結果。
02
AI 拆解 brief
LLM 將自然語言需求拆成：交付物清單 / 範圍邊界 / 驗收標準 / 時程估計 / 預算落點。
03
確認期待
把拆解結果回給客戶用「你想要的是不是 X、不是 Y」對焦。90% 的「我以為他懂」誤會在這裡截掉。
04
AI 自動配對
基於 5 維演算法給客戶 3 人短名單 + 每位候選人的「為什麼是他」具體理由。
05
接案者接案
候選人 72 小時內回應接 / 拒 / 修正報價。婉拒不影響 Tier、只有延宕會。
06
合作條件
雙方在平台內談 Milestone / 付款 / IP / NDA。範本由 BeyondPath 提供。
07
驗收框架
合約簽好同時、Milestone 驗收標準 lock。事前定義「達成 / 未達 / 爭議」三種狀態。
08
案件儀表板
客戶看得到 Milestone 完成度 / 工時投入 / 產出版本 / 預期 vs 實際差距。給「不焦慮」的可見度。
09
Milestone 驗收
客戶 7 天內回 Pass / Revise / Reject。Pass 自動釋款；Revise 一輪修改；Reject 進仲裁。
10
雙邊 NPS
結案後雙方互評 0-10 + 質性回饋。直接餵到接案者 Tier 計算 + 客戶下次配對權重。
11
Tier 飛輪
接案者 Tier 動態升降。有反馬太機制——3 個月無接案自動加 capacity、避免活躍 worker 壟斷。
12
Retainer 提案
第二案結束 + 雙邊 NPS > 8、平台自動提案 Retainer（月 / 季 / 年簽）、把單次合作升級成長期關係。
▸ 設計原則

12 步協定不是把每件事流程化、是把「不確定的事情」事先想完。哪一步會出錯、出錯了 fallback 是什麼、誰來收尾——這些不該等到出事才想。

ENGINES · 6 個核心引擎

六個摩擦點、一個一個拆。

每個引擎對應一個「過去靠人扛、現在靠演算法 + AI + 流程系統化」的摩擦點。

01客戶提案理解● LIVE

把「我想要做 AI 內容」這種模糊需求、拆成 LLM 看得懂的結構化規格。輸入可中文 / 英文 / 語音 / 截圖 / PDF——輸出是品牌主能對焦、接案者能報價、平台能配對的三方共用語言。

02AI 拆解 / 範圍鎖定● LIVE

需求拆完、引擎自動推出範圍邊界：什麼算交付物、什麼算 extra、什麼是規格灰色地帶。Lock 完成才能進配對——避免接案者接了案才發現「啊原來還要 X」。

035 維配對演算法● LIVE

領域 30% / Tier 25% / capacity 20% / L-score 15% / 反馬太 10%——五個維度算每位候選人的 match score。給客戶 top 3 + 推薦理由；給接案者「為什麼你被推 + 對手是誰」。

04邀請信閉環● LIVE

配對完成後、引擎自動寄邀請信給接案者——附 brief 摘要 + 預算範圍 + 競爭情況。72 小時內回應、引擎追蹤每封信狀態、自動 fallback 到下一輪。

05簽約自動化● LIVE

合作條件談妥即生成電子合約——含 SHA-256 簽章 + 雙方手寫簽 + 平台時間戳。任何時候可在 合約查驗頁 上傳本機檔比對、驗真。

06Retainer 引擎○ COMING

第二案結束 + 雙邊 NPS > 8、引擎主動向雙方提案 Retainer：月費 / 季簽 / 年簽——把單次合作升級成長期關係。對接案者是穩定收入、對客戶是免每次重新找人。

TIER · 5 階認證飛輪

Tier 不是裝飾、是推薦排序權重。

每位接案者都有透明 Tier 等級。升降條件公開、不黑箱。接案者看得到「升級還差什麼」、客戶看得到「這個人為什麼貴」。

▸ 「給人機會」原則 · 反馬太機制

純演算法配對會把所有案子推給 top 幾位、對新人不公平、市場長期不健康。內建三層機會分：首案池（前 3 案優先給認證新人）、新認證加成（領域新認證者 +15 分一個月）、久未接案再啟動（3 個月無接案自動 +10 分）。

TRUST · 信任 / 驗收 / 爭議

AI 降不確定性、人覆核建信任。

合作出事不可怕、可怕的是出事了沒人收尾。事前就把驗收標準、爭議流程、違約金倍率寫清楚——出事時不靠 email 爭辯、靠流程仲裁。

線上簽約閉環

每份合約有 SHA-256 簽章 + 雙方手寫簽 + 平台時間戳。任何時候可上 合約查驗頁 比對本機檔、確認是平台正本不是被竄改的版本。

驗收 5 情境

  • PASS · 客戶 7 天內回 Pass → 自動釋款 + 接案者 L-score +1 + 進下個 milestone
  • REVISE · 客戶要求一輪修改（不額外計費）→ 接案者 5 天提交修改版 + 再 7 天 review
  • REJECT · 客戶明確拒收 → 凍結款項 + 雙方提交立場文件 + 平台 5 工作日仲裁
  • TIMEOUT · 客戶 7 天無回應 → 默認 Pass + 自動釋款（避免拖款）
  • 雙邊終止 · 雙方協議提前結案 → 已完成 milestone 結算 + 未完成依協議退

違約金倍率

  • 接案者接案後無故延宕、客戶取消 → 賠 原合約金額 ×2
  • 客戶簽約後無故取消、接案者已啟動 → 賠 原合約金額 ×1.5
  • 惡意違約（IP 侵權 / 機密外洩 / 人身攻擊） → 賠 原合約金額 ×3 + 平台禁訪 6 月

詳見 服務條款 §8。

▸ 為什麼這些都先寫清楚

合作開始前談爭議聽起來不吉利。但出事的時候、雙方都希望「對方早就知道規則」——這就是事前說清楚的價值。BeyondPath 不希望任何一次合作走到仲裁、但每份合約都假設它可能會發生。

MOAT · 為什麼是 BeyondPath

LLM 可以推薦人。
但信任來自交付證據。

當所有人都可以用 ChatGPT 找 freelancer、BeyondPath 還剩什麼？我們建立的不是「比 AI 更會配對」、是 AI 工作的信任資料層：誰能把哪一類需求交付出來、用什麼 workflow、結果如何被驗收、下次為什麼值得推薦。

我們不是更好的 marketplace

對標 Upwork 是不公平的——我們不打算做全球泛用平台、不靠 commission 規模化、也不做 race-to-the-bottom 的低價市場。

BeyondPath 是台灣品牌主與認證化 AI workforce之間的中介層——先把信任跑穩、再談規模。對標長期不是 Upwork、是 Stripe Atlas + AWS + Substack 三合一：一人公司時代的客戶層 + 履約層 + 認證層的 OS。
